# 추천에 쓰이는 MVP 데이터

> 상위 문서: [개발 계획](README.md) · 같은 묶음: [첫 대화 온보딩 · 챗봇 설정](onboarding.md) · [역할 분담 · 작업 순서](roles.md)

MVP 에서 검색 · 추천에 실제로 쓰는 정보와 아직 안 쓰는 정보. 단계별 범위는 [plan.md](README.md)

## 1. 작품 쪽 (검색 인덱스 `works_ai`)

| 정보 | 어디에 쓰나 | 근거 |
| --- | --- | --- |
| 작품 설명 | 임베딩(의미 검색) + BM25(키워드 검색) | 명시 |
| 태그(해시태그) | 임베딩 + BM25 | 명시 |
| 장르 | 임베딩 + BM25, 조건 추출 결과로 거르기 | 명시 |
| 성인 작품 여부 | 필수 필터 | 명시 |
| 연재 / 완결 | 필수 필터 | 명시 |
| 작품 유형 (웹툰 / 웹소설) | 필수 필터 | 명시 |
| 플랫폼 | 필터 | 예시("카카오페이지 웹툰만")로만 나옴 |

- 설명 · 태그 · 장르는 작품당 문서 하나(`embed_text`)로 합쳐서 임베딩
- 제목 · 표지 · 플랫폼은 순위에 쓰지 않고, 답변이 나온 뒤 카드를 채울 때만 DB 에서 가져옴

## 2. 사용자 쪽

| 정보 | 출처 | MVP 에서 쓰는 방식 |
| --- | --- | --- |
| 서재 등록 작품 ID | 내부 API | 추천 결과에서 제외 |
| 관심작품 ID | 내부 API | 가져오기는 함. "비슷한 작품 추천 가능"만 정해져 있고 순위 반영 방법은 없음 |
| 취향 | 내부 API | 조회 대상에 있음. MVP 에서 어디에 쓰는지는 안 정해짐 |
| 성인 인증 여부 | Spring 판단 | 미성년자는 성인 작품 필터 |
| 19금 추천 on/off | `ai_chat_settings` | 성인 작품 필터 |
| 기본 작품 유형 | `ai_chat_settings` | 질문에 유형이 없을 때 대신 사용 |

## 3. 대화 쪽 (Redis)

| 정보 | 쓰는 방식 |
| --- | --- |
| 최근 대화 25개 | 후속 질문 이해 ("그거 말고 완결된 걸로") |
| 이미 보여 준 작품 ID | 같은 작품을 다시 추천하지 않기 |
| 사용자가 붙인 조건 | 대화 안에서 조건 유지 |

## 4. 질문에서 뽑는 조건 (Haiku)

작품 유형 · 장르 · 완결 여부 · 범위 밖 여부

- 파이프라인 ① 에는 소재 · 분위기도 있지만 MVP 작업 목록(AI-06)에는 빠져 있음. 팀 확인 필요

## 5. MVP 에서 안 쓰는 것

| 정보 | 언제 들어오나 |
| --- | --- |
| 별점 | 계획에 없음 |
| 리뷰 · 피드 · 토픽룸 (UGC) | v2 |
| 표지 이미지 특징 | v2 (VLM 라벨) |
| 인기 지표 (관심작품 수, 최근 반응) | v2 재순위 |
| 조회수 · 완독 · 읽는 중 같은 행동 데이터 | 계획에 없음 |
| 작가 · 연재 시작일 | 계획에 없음 |
