# 개발 계획

- MVP 먼저 내고, 검색 알고리즘은 STORIX-AI 만 따로 배포해서 개선한다
- 알고리즘을 바꿀 때마다 같은 평가 세트로 숫자를 비교하고 나아졌을 때만 배포한다
- 0~2단계까지 개발하고, 3단계는 실제 사용 패턴을 보고 정한다

## 1. 단계

| 단계 | 목표 | 범위 |
| --- | --- | --- |
| 0. 준비 | 같이 일할 수 있는 바닥 | API 계약, mock API, 레포 · 배포 경로, 평가 세트 초안 |
| 1. MVP | 대화로 작품 5개 추천이 끝까지 동작 | 작품 DB 기반 검색, 조건 추출, 스트리밍 답변, 대화 저장, 범위 밖 · 19금 처리 |
| 2. 알고리즘 v2 | 검색 품질 올리기 | 재순위, 표지 라벨, UGC 색인, 지난 대화 요약 |
| 3. 확장 | 쓰임새 넓히기 | 그림체 비슷한 작품, 외부 서칭, 에이전트 비서 · 먼저 추천 알림 |

## 2. 정해진 정책

| 정책 | 구현 위치 |
| --- | --- |
| 추천 카드 최대 5개 | ⑦ 답변 도구 스키마 · Spring 검증 |
| 범위 밖 질문(사담 · 날씨 · 프롬프트 조작)은 고정 문구 | ① 조건 추출에서 분류 → 고정 문구 |
| 미성년자는 성인 작품 추천 안 함, 성인은 설정으로 켜고 끔 | ② 필수 필터. Spring 이 판단해 전달 |
| 말투는 ~해요체 | `prompts/system.md` |
| 서재 작품 제외, 관심작품과 비슷한 작품은 추천 가능 | ② 필수 필터 · 내부 API |
| 새 작품은 적재될 때 바로 반영 | 증분 색인 API |
| 대화는 탈퇴 시까지 보관, 모델은 최근 25건만 읽고 이전은 요약 | MVP: 최근 25건 / v2: 요약 · 색인 |
| 사용 횟수 제한은 우선 없음 | Spring 에 자리만, 비용 지표는 수집 |

## 3. 기대 결과와 기준

### MVP: 작품 설명 · 태그 · 장르에 적힌 것까지

| 잘 되는 질문 | 약한 질문 (채우는 단계) |
| --- | --- |
| "회귀 복수물 판타지 웹소설" | "은발 꼬마랑 흑발 아빠 나오는 거" (v2 표지 라벨) |
| "계약결혼 로판 중에 완결된 거" | "고구마 없는 사이다물" (v2 리뷰 색인) |
| "집착남 나오는 거" | "그림체 예쁜", "파스텔톤" (3단계) |
| "카카오페이지 웹툰만", "19금 빼고" | "요즘 핫한 거" (v2 재순위) |

| MVP 출시 기준 | 목표 |
| --- | --- |
| 장르 · 소재 · 조건 질문 | Recall@10 70% 이상, Precision@5 60% 이상 |
| 외형 · 분위기 · 독자 평가 질문 | 측정만, v2 기준선 |
| 지어낸 작품 · 성인 노출 | 0건 |
| 범위 밖 질문 차단 | 95% 이상 |

예상 속도: 첫 글자 2~3초, 카드까지 5~10초 (측정 전 추정)

### v2: 표지 · 리뷰 · 인기 반응까지

진행 순서: 재순위 + 인기 점수 → 표지 라벨 → 리뷰 색인 → 피드 · 토픽룸 색인 → 지난 대화 요약

| v2 배포 기준 | 목표 |
| --- | --- |
| 외형 · 분위기 · 독자 평가 질문 | MVP 대비 Recall@10 이 오를 때만 |
| 장르 · 소재 · 조건 질문 | MVP 대비 떨어지지 않음 |
| 지어낸 작품 · 성인 노출 | 0건 유지 |
| 단서 출처 정확도 | 90% 이상 |
| 첫 글자 시간 · 답변당 비용 | MVP 대비 +1초 · +40% 이내 |

주의: UGC 를 따로 색인하면 ES 메모리가 크게 늘어남. 리뷰 색인 전에 ES 용량 확인

## 4. 평가 지표

| 구분 | 지표 | 보는 것 |
| --- | --- | --- |
| 사전 (평가 세트) | Recall@10 | 정답 작품이 후보 안에 들어왔나 |
| 사전 | Precision@5 | 추천한 5개 중 맞는 비율 |
| 사전 | 후보 밖 작품 비율 | 없는 작품을 지어냈나 |
| 사전 | 조건 추출 정확도 | 질문에서 조건을 맞게 뽑았나 |
| 사전 | 범위 밖 차단율 · 성인 노출 | 정책을 지키나 |
| 사후 (실사용) | 카드 클릭률 · 관심작품 추가율 (GA) | 추천이 쓸모 있었나 |
| 사후 | 대화당 다시 묻는 횟수 | 한 번에 찾았나 |
| 사후 | 첫 글자 · 전체 응답 시간, 답변당 토큰 · 비용 | 기다릴 만한가, 예산 안인가 |

- 평가 세트는 생성형 AI 로 초안을 만들고 사람이 검수한다. 원본은 커밋하지 않는다
