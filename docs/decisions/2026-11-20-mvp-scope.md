# MVP 범위와 구조

- 날짜: 2026-11-20
- 상태: 확정

## 결정

| 항목 | 결정 | 이유 |
| --- | --- | --- |
| 구조 | 앱 → Spring → FastAPI. FastAPI 는 인터넷에 열지 않음 | 인증 · 사용 제한 · 정책을 Spring 한 곳에서 관리 |
| 사용자 데이터 | FastAPI 는 DB 에 직접 붙지 않고 Spring 내부 API 호출 | 비공개 · 차단 · 성인 규칙이 두 군데로 갈리지 않게 |
| LLM | Haiku 로 조건 추출, Sonnet 으로 답변 | 싼 모델로 분류, 답변 품질은 Sonnet |
| 추천 개수 | 최대 5개 | 회의 결정 |
| 작품 반영 | 적재될 때 바로 증분 색인 | 회의 결정 |
| 대화 | 탈퇴 시까지 보관, 모델은 최근 25건, 이전은 요약 (v2) | 회의 결정 |
| MVP 검색 데이터 | 작품 설명 · 태그 · 장르만 | 표지 라벨 · UGC 는 데이터 준비 · ES 용량 확인이 필요해 v2 |
| 전체 재색인 | 비공개 레포 STORIX-AI-Hub 에서 팩으로 빌드 · 평가 · 배포 | 서비스 서버에서 재색인하면 CPU · 메모리를 잡아먹음. 데이터를 공개 레포에 두지 않기 위해 |
| 레포 공개 | STORIX-AI 는 공개, 데이터는 커밋하지 않음 | 작품 · UGC 는 저작권 · 개인정보 문제로 공개 불가 |
