# Elasticsearch 위치

- 날짜: 2026-11-23
- 상태: 확정 (작업은 STORIX-BE-2.0 #439)

## 결정

| 항목 | 결정 | 이유 |
| --- | --- | --- |
| Elasticsearch | 앱 서버에서 빼서 **기존 모니터링 서버**로 옮긴다. 9200 은 prod · dev 보안 그룹에서만 열고 사설 주소로 붙는다 | 앱 서버(t4g.medium 4GB)에 ES 1GB 가 있어 AI 서버 · 질문 임베딩 모델 자리가 없다 |
| 모니터링 | Prometheus · Loki · Grafana 는 Grafana Cloud(Grafana Labs)로 옮기고 기존 모니터링 서버에서 내린다 | 모니터링이 우리 서버 안에 있으면 같이 죽을 때 알림도 끊긴다. 지표 · 로그 양이 무료 한도 안 |
| AI 서버 | 앱 서버에 그대로 둔다 (`storix-net`, 밖에 안 엶) | ES 가 빠지면서 생기는 메모리를 AI 서버 · 임베딩 모델에 쓴다 |

- "모니터링 서버"는 이름만 남은 기존 EC2 를 말한다. 옮긴 뒤에는 ES 전용 서버가 된다
- AI 서버는 ES 를 서버 하나 건너 부르게 된다. 검색 지연은 AI-07b 에서 잰다
- ES 메모리(UGC 색인 전 용량 확인)는 HUB-08 에 그대로 남는다
