# 대화방 하나 · 앱 API 경로

- 날짜: 2026-11-22
- 상태: 확정

## 결정

| 항목 | 결정 | 이유 |
| --- | --- | --- |
| 대화방 | 사용자당 하나를 이어서 쓴다. 대화방 생성 API 는 두지 않고, 온보딩 저장 · 첫 질문 때 서버가 만든다 | 진입 버튼이 하나고, 들어가면 처음에만 온보딩을 보여 주고 그다음은 대화만 이어진다 |
| 진입 | `GET /api/v1/ai/chat` 하나로 온보딩 노출 여부 · 멘트 · 선택지 · 예시 질문을 내려준다. 예시 질문 API 는 따로 두지 않는다 | 화면 하나에 필요한 값을 한 번에 |
| 경로 | `/api/v1/ai-search` 대신 `/api/v1/ai/chat` | 리소스가 대화다. 다른 AI 기능도 `/api/v1/ai/` 아래에 둔다 |
| BE 도메인 이름 | `aichat` (클래스 `AiChat...`) | 토픽룸 채팅 `chat` 도메인과 섞이지 않게 |
| 메시지 역할 | `USER` · `CHATBOT`. AI 서버 맥락에 넘길 때만 `user` · `assistant` 로 바꾼다 | 화면 용어와 맞춤 |
| 사용 횟수 | MVP 에 제한 없음. 응답에 남은 횟수도 넣지 않는다 | [MVP 범위](2026-11-20-mvp-scope.md) 결정 유지. 디자인의 "오늘 N회 남음" 문구는 빼고 간다 |
| 챗봇 이름 | 미정. 멘트에는 "○○" 로 둔다 | |
